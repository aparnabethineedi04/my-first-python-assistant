
# My First Python Assistant

## About the Project

My First Python Assistant is a beginner-friendly, rule-based assistant built using Python. It helps users organize tasks, create simple plans, search saved notes, and read text files.

This project was created to practise Python programming, functions, loops, file handling, and data storage.

## Features

- Create simple plans based on goals
- Add and save tasks
- Display saved tasks
- Mark tasks as completed
- Prevent duplicate tasks
- Save and search notes
- Read text files
- Display the current date and time
- Display a help menu

## Technologies Used

- Python
- JSON for task storage
- Text files for notes
- Python standard library

## Project Files

- `free_assistant_v8.py` — Main assistant program
- `agent_tools.py` — Helper functions for notes and other tools
- `tasks.json` — Saved task data
- `notes.txt` — Saved notes
- `my_notes.txt` — Sample text file
- `.gitignore` — Files excluded from version control

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

   ```bash
   python free_assistant_v8.py
   ```

5. Type `help` to see the available commands.
